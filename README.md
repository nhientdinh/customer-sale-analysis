# E-Commerce Customer & Sales Analysis

## Overview

SQL-based analysis of e-commerce customer behavior and sales performance using MySQL.

## Tools

- MySQL
- SQL
- GitHub

 ## Project Files

- [SQL Analysis](sql/ecommerce_analysis.sql)

## Business Questions

- How many customers and orders are in the dataset?
- How frequently do customers make purchases?
- Which product categories generate the most revenue?
- How does sales performance change over time?
- Is customer rating related to average order value?
  
## Key Findings

- The dataset contains 17,409 orders from 5,000 unique customers.
- Customers place an average of 3.41 orders each.
- 82.16% of customers are repeat customers, while 17.89% are one-time customers.
- Electronics generates approximately 48% of total revenue.
- Electronics has a substantially higher average order value than other product categories, driven primarily by higher unit prices.
- Monthly order volume remains relatively stable, while average order value varies across months.
- Customer ratings do not appear to have a strong relationship with average order value.
